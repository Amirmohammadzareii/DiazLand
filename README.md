# 🇩🇿 جمهوری دیازلند

> آخرین پناهگاه آزادی در اینترنت فارسی.

یک «کشور مجازی» سرگرمی: تابعیت بگیر، پاسپورت طلایی بگیر، هر روز حقوق (ارز **دیاز**) دریافت کن، از فروشگاه ملی خرید کن و در لیدربورد رقابت کن.

این نسخه **MVP** است — تمیز، سبک و قابل‌گسترش.

---

## ✨ امکانات

### فاز ۱ — هسته
| قابلیت | توضیح |
|---|---|
| 🛂 پاسپورت شهروندی | کارت پاسپورت CSS با افکت three-tilt، پرچم دیزلند، شماره ملی خودکار، امضای رئیس‌جمهور و **دانلود PNG** |
| 💰 حقوق روزانه | هر ۲۴ ساعت ۱۰ دیاز + کانفتی طلایی |
| 🏪 فروشگاه ملی | ۸ کالای طنز با hover pop و tooltip «تو فقییرت» + کانفتی بعد از خرید |
| 🏆 لیدربورد | ۱۰ شهروند ثروتمند با مدال طلا/نقره/برنز، میکرو-پاسپورت و count-up |
| ⚙️ پنل ادمین | مدیریت شهروندان و تغییر دستی موجودی |

### فاز ۲ — لندینگ سینمایی اسکرولی + نقشه
| قابلیت | توضیح |
|---|---|
| 🎬 لندینگ ۶ صحنه‌ای | تجربه اسکرولی (به سبک Xiaomi): Hero ستاره‌ای / پاسپورت / حقوق / تیزر نقشه / لیدربورد زنده / CTA |
| ⭐ Hero ستاره‌ای | canvas با ۱۲۰ ستاره چشمک‌زن (۶۰ در موبایل) + شهاب هر ۴-۶ ثانیه، pause وقتی تب مخفی |
| ✨ انیمیشن ورود صحنه | IntersectionObserver (threshold 0.25، یک بار) — opacity + translateY |
| 🔢 count-up | اعداد لیدربورد با rAF و easing نرم از ۰ تا مقدار واقعی |
| 🗺️ نقشه کشور | گرید شش‌ضلعی ۱۶×۱۶ (۲۵۶ قطعه) با SVG — مرکز = پایتخت |
| 💰 قیمت‌گذاری | `round(200 × 1.18^distance)` — حاشیه ≈۲۰۰، مرکز ≈۵۰۰۰ دیاز |
| 🎨 رنگ‌بندی | خالی خاکستری، مال کاربر طلایی، دیگران رنگ اختصاصی از هش نام کاربری |
| 🖱️ تعامل | هاور tooltip، کلیک روی قطعه خالی → مودال خرید، زوم/پن (موس + لمسی) |
| 🏗️ صفحه ملک | نام صاحب، نوع بنا (قصر/خانه/باغ/فواره/مغازه)، پیام (حداکثر ۱۰۰ حرف)، ویرایش توسط صاحب |
| 🚩 پرچم رسمی | SVG (assets/flag.svg + partial) — سرمه‌ای + مثلث طلایی گرادیانی + ۸ ستاره سفید |
| 📊 آمار زنده | API `/api/stats` برای شمارنده شهروندان |

## 🧱 استک فنی

- **Python 3** + **FastAPI**
- **SQLite** (با `sqlite3` استاندارد — بدون ORM)
- **Jinja2** برای قالب‌بندی
- **TailwindCSS** (CDN) + فونت **Vazirmatn** (CDN)
- **itsdangerous** برای session کوکی امضاشده
- **pbkdf2** برای هش رمز عبور

تمام صفحات **RTL** و **فارسی** هستند. تم تیره: پس‌زمینه `#0b0f19`، طلایی ملی `#f5c542`.

## 🚀 نصب و اجرا

```bash
# 1) محیط مجازی
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

# 2) نصب وابستگی‌ها
pip install -r requirements.txt

# 3) تنظیم متغیرهای محیطی
cp .env.example .env
# مقدار SECRET_KEY را پر کنید:
python -c "import secrets; print(secrets.token_hex(32))"

# 4) اجرای سرور
uvicorn app:app --port 8000
```

سپس مرورگر: **http://localhost:8000**

> دیتابیس `diazland.db` و آیتم‌های فروشگاه به‌صورت **خودکار** در اولین اجرا ساخته می‌شوند.

## 🔐 امنیت

- رمزها با **pbkdf2_hmac (sha256, 200k iterations)** هش می‌شوند.
- session با کوکی **امضاشده** (`itsdangerous`) و `httponly` + `samesite=lax`.
- `SECRET_KEY` **فقط از متغیر محیطی** خوانده می‌شود — هرگز هاردکد نمی‌شود.
- فایل‌های `.env` و `*.db` در `.gitignore` هستند.

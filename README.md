# 🎬 دیازفلیکس (DiazFlix)

> سینمای آنلاین فارسی — **بدون سرور، بدون بک‌اند، بدون هزینه‌ی هاست.**

دیازفلیکس یک وب‌اپ کاملاً استاتیک است: کاتالوگ فیلم‌ها یک فایل ساده `data/movies.json` داخل همین ریپو است و پخش ویدیو **مستقیم از تلگرام** انجام می‌شود. یعنی نه دیتابیس داری، نه سرور، نه قبض ماهانه.

---

## ✨ ویژگی‌ها

| قابلیت | توضیح |
|---|---|
| 🏠 صفحه اصلی | هدر چسبان نئونی، hero فیلم شاخص، ردیف‌های افقی به تفکیک ژانر، بخش «تازه‌ها» |
| 🔍 جستجوی زنده | جستجو در عنوان، ژانر و سال (با debounce) |
| 🎴 کارت پوستر | هاور → بزرگ‌نمایی + نشانه پخش + امتیاز و سال |
| 📄 صفحه فیلم | backdrop، عنوان، متادیتا، توضیح، امتیاز ستاره‌ای، دکمه پخش |
| ▶ پخش داخلی | embed تلگرام در iframe (بدون redirect) + fallback دوستانه |
| ⏯ ادامه تماشا | پیشرفت در `localStorage` + نوار پیشرفت روی پوستر + دکمه حذف |
| ⭐ امتیاز کاربر | ستاره‌های شخصی، ذخیره در `localStorage` |
| ℹ️ صفحه about | معرفی + راهنمای کامل افزودن فیلم برای مدیر |

## 🚀 راه‌اندازی (اجرای محلی)

چون استاتیک است، فقط یک سرور ساده لازم داری (باز کردن مستقیم `index.html` کار نمی‌کند چون `fetch` روی `file://` بلاک می‌شود):

```bash
# پایتون
python3 -m http.server 8080

# یا Node
npx serve .
```

سپس مرورگر: **http://localhost:8080**

## 🌐 انتشار روی GitHub Pages

1. تغییرات را به شاخه‌ی `main` (یا شاخه‌ی دلخواه) پوش کن.
2. در گیت‌هاب برو به **Settings → Pages**.
3. زیر **Source** گزینه‌ی **Deploy from a branch** را انتخاب کن.
4. شاخه را انتخاب کن (مثلاً `main`) و پوشه را روی **/ (root)** بگذار.
5. **Save** بزن. چند دقیقه بعد سایت روی این آدرس بالا می‌آید:
   `https://<username>.github.io/<repo>/`

> ✅ همه‌ی مسیرها در این پروژه **relative** هستند، پس زیر subpath گیت‌هاب پیجز هم درست کار می‌کند.

## ➕ چطور فیلم اضافه کنم؟ (راهنمای مدیر)

مدیریت کاتالوگ **دستی** است — فقط JSON ویرایش می‌کنی:

1. **آپلود در تلگرام:** فیلم را در کانال تلگرام خودت آپلود کن.
2. **گرفتن لینک پست:** روی پیام آپلودشده کلیک کن → «Copy Link».
   لینک به شکل `https://t.me/your_channel/123` است.
3. **پوستر:** تصویر پوستر (نرخ تصویر **۲:۳**) را در `assets/posters/` بگذار
   (مثلاً `assets/posters/my-movie.jpg`).
4. **ویرایش کاتالوگ:** فایل `data/movies.json` را باز کن و یک شیء جدید به آرایه اضافه کن:

```json
{
  "id": "my-movie-1",
  "title": "نام فیلم",
  "year": 1403,
  "genres": ["کمدی", "خانوادگی"],
  "rating": 8.0,
  "duration": "1:45",
  "description": "توضیح دو-سه خطی درباره فیلم.",
  "poster": "assets/posters/my-movie-1.jpg",
  "telegram_embed": "https://t.me/your_channel/123",
  "added_at": "2026-10-29"
}
```

5. **کامیت و پوش:** تمام! فیلم روی سایت ظاهر می‌شود.

### توضیح فیلدها

| فیلد | توضیح |
|---|---|
| `id` | شناسه یکتا (انگلیسی، بدون فاصله) — در URL استفاده می‌شود |
| `title` | نام فیلم (فارسی) |
| `year` | سال ساخت |
| `genres` | آرایه‌ی ژانرها — هر ژانر یک ردیف جدا در صفحه اصلی می‌سازد |
| `rating` | امتیاز کلی (۰ تا ۱۰) |
| `duration` | مدت (مثل `1:52`) |
| `description` | توضیح کوتاه |
| `poster` | مسیر relative پوستر (۲:۳) |
| `telegram_embed` | لینک پست تلگرام |
| `added_at` | تاریخ افزودن (برای بخش «تازه‌ها» و hero) |

## 🧪 تست خودبازبینی (چک‌لیست)

چون بک‌اندی نیست، کیفیت با یک اسکریپت خودبازبینی چک می‌شود:

```bash
node test/selfcheck.js
```

این اسکریپت موارد زیر را بررسی می‌کند:

- ✅ وجود فایل‌های ضروری
- ✅ اعتبار `movies.json` (آرایه، حداقل ۸ فیلم، فیلدهای لازم، idهای یکتا، پوسترهای موجود)
- ✅ **relative بودن همه‌ی مسیرها** (سازگاری با GitHub Pages subpath)
- ✅ وجود همه‌ی hash routeها (`#/`، `#/movie/:id`، `#/about`، `#/search/:q`)
- ✅ کلیدهای `localStorage` (ادامه تماشا + امتیاز)
- ✅ تبدیل لینک تلگرام به embed + fallback
- ✅ جستجوی زنده
- ✅ **نبود هیچ secret یا توکن در کد**
- ✅ وجود راهنمای افزودن فیلم در README

### چک‌لیست دستی (در مرورگر)

| مورد | انتظار |
|---|---|
| باز کردن `#/` | صفحه اصلی با hero + ردیف‌های ژانر |
| کلیک روی کارت | رفتن به `#/movie/:id` |
| دکمه «▶ پخش الآن» | iframe تلگرام باز شود (یا fallback) |
| تایپ در جستجو | فیلتر زنده + رفتن به `#/search/:q` |
| کلیک روی ستاره‌ها | ذخیره امتیاز + ماندن بعد از رفرش |
| بازگشت به خانه | ردیف «ادامه تماشا» با نوار پیشرفت |
| دکمه ✕ روی پوستر | حذف از ادامه تماشا |
| `#/about` | راهنمای افزودن فیلم |

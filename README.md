# 🇩🇿 جمهوری دیازلند

> آخرین پناهگاه آزادی در اینترنت فارسی.

یک «کشور مجازی» سرگرمی: تابعیت بگیر، پاسپورت طلایی بگیر، هر روز حقوق (ارز **دیاز**) دریافت کن، از فروشگاه ملی خرید کن و در لیدربورد رقابت کن.

این نسخه **MVP** است — تمیز، سبک و قابل‌گسترش.

---

## ✨ امکانات

| قابلیت | توضیح |
|---|---|
| 🏠 صفحه اصلی | لندینگ مدرن با انیمیشن لطیف و تم تیره طلایی |
| 🛂 پاسپورت شهروندی | کارت پاسپورت CSS با پرچم دیزلند، شماره ملی خودکار و امضای رئیس‌جمهور |
| 💰 حقوق روزانه | هر ۲۴ ساعت ۱۰ دیاز (با جلوگیری از تکرار) |
| 🏪 فروشگاه ملی | ۸ کالای طنز — خرید با دیاز و ثبت در دارایی‌ها |
| 🏆 لیدربورد | ۱۰ شهروند ثروتمند کشور |
| ⚙️ پنل ادمین | مدیریت شهروندان و تغییر دستی موجودی |

---

## 🧱 استک فنی

- **Python 3** + **FastAPI**
- **SQLite** (با `sqlite3` استاندارد — بدون ORM)
- **Jinja2** برای قالب‌بندی
- **TailwindCSS** (CDN) + فونت **Vazirmatn** (CDN)
- **itsdangerous** برای session کوکی امضاشده
- **pbkdf2** برای هش رمز عبور

تمام صفحات **RTL** و **فارسی** هستند. تم تیره: پس‌زمینه `#0b0f19`، طلایی ملی `#f5c542`.

## 🚀 نصب و اجرا

```bash
# 1) محیط مجازی
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

# 2) نصب وابستگی‌ها
pip install -r requirements.txt

# 3) تنظیم متغیرهای محیطی
cp .env.example .env
# مقدار SECRET_KEY را پر کنید:
python -c "import secrets; print(secrets.token_hex(32))"

# 4) اجرای سرور
uvicorn app:app --port 8000
```

سپس مرورگر: **http://localhost:8000**

> دیتابیس `diazland.db` و آیتم‌های فروشگاه به‌صورت **خودکار** در اولین اجرا ساخته می‌شوند.

## 🧪 تست

سرور را بالا بیاورید، سپس در ترمینال دیگر:

```bash
python smoke_test.py
```

جریان تست: ثبت‌نام → پاسپورت → حقوق → فروشگاه → خرید → لیدربورد → خروج → ورود مجدد.

## 🔐 امنیت

- رمزها با **pbkdf2_hmac (sha256, 200k iterations)** هش می‌شوند.
- session با کوکی **امضاشده** (`itsdangerous`) و `httponly` + `samesite=lax`.
- `SECRET_KEY` **فقط از متغیر محیطی** خوانده می‌شود — هرگز هاردکد نمی‌شود.
- فایل‌های `.env` و `*.db` در `.gitignore` هستند.
